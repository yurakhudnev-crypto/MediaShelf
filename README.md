# 📚 MediaShelf — Моя медиатека

Приложение для отслеживания потреблённого медиа-контента: фильмы, книги, музыка и видеоигры.

![MediaShelf](https://img.shields.io/badge/status-active-success)
![React](https://img.shields.io/badge/React-18-blue)
![Vite](https://img.shields.io/badge/Vite-6-purple)

## ✨ Возможности

- 📚 🎬 🎵 🎮 Отслеживание книг, фильмов, музыки и видеоигр
- 🖼️ Pinterest-стиль галерея с обложками
- 🔍 Поиск по названию и комментариям
- ⭐ Рейтинги и личные впечатления
- 📌 Раздел «На будущее» — что хочу потребить
- 🎨 Динамический фон из цвета обложки в деталях
- 📱 PWA — работает оффлайн, можно установить на телефон
- 💾 Хранение данных в localStorage + экспорт/импорт JSON
- 🔗 Интеграция с Google Drive для хранения обложек

## 🚀 Локальный запуск

```bash
npm install
npm run dev
```

## 📦 Сборка

```bash
npm run build
```

## 🌐 Деплой на GitHub Pages

1. Форкните репозиторий
2. В `vite.config.js` замените `/mediashelf/` на имя вашего репозитория
3. Settings → Pages → Source: GitHub Actions
4. Сайт будет доступен по адресу `https://USERNAME.github.io/mediashelf/`

## 🛠 Технологии

- React 18 + TypeScript
- Vite 6
- Tailwind CSS 4
- Framer Motion (анимации)
- Lucide React (иконки)
